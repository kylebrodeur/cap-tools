Video Recording Cheatsheet

Reference guide for screen recordings that will be used to auto-generate HTML admin guides

⚙️ Before You Hit Record

  • Set browser zoom to 100% (Cmd/Ctrl + 0)
  • Fix window to a consistent size — don't resize mid-recording
  • Hide or show bookmarks bar consistently across all clips
  • Close unneeded tabs (keep only what's relevant)
  • Clear personal info from visible URL fields if needed
  • Increase cursor size in System Preferences → Accessibility (easier to track in screenshots)
  • Know your outline — what steps, in what order, what "parts"?
  • Have the transcript tool ready to run immediately after recording

⭐ The Four Golden Rules

  • Pause 2 seconds on every meaningful UI state before moving on
  • Say the name of every tab, section, or setting you click
  • Move the cursor away from buttons/links when pausing (hover states pollute screenshots)
  • One video per logical section — don't try to cover 10 steps in one long take if you can help it

These four things alone will eliminate ~80% of the cleanup work on the guide generation side.

🎙️ What to Say While Recording

Use these phrases out loud — the transcript maps them to exact timestamps.

Navigating to a section:

"Now I'm clicking on the [Tab / Section Name] tab."
"This is the [Section] section — I'll scroll down to show all the settings."

Calling out important settings:

"The key setting here is [Setting Name] — it's currently set to [Value]."
"Note: [setting or warning the admin needs to know]."

Marking the end of a section:

"That covers Part 1 — now moving to Part 2."
"That's all the settings under Properties."

🗂️ Recording Tabbed / Multi-Panel UIs

Settings panels with multiple tabs (like Acme Properties) need special treatment. Each tab needs its own clean frame.

The pattern for each tab:

  1. Click the tab
  2. Say its name out loud
  3. Move cursor off to a neutral area
  4. Pause 2 full seconds
  5. If content is long, scroll to show it, then pause again
  6. Move to the next tab

Best practice: record tabs as a separate short clip

A dedicated 30–60 second clip just for the settings panel (like properties-tabs.mp4) is far more useful than trying to pull those frames from a longer recording. You can do corrections later without re-recording the whole workflow.

✅ / ❌ Do and Don't

✅ DO
  • Pause on each step for 2+ seconds before moving
  • Show the URL bar when on key pages (the URL often contains the activity code or ID)
  • Narrate tab and section names as you navigate to them
  • Say "note:" or "important:" before any gotcha/warning — these become callout boxes
  • Record separate short clips for complex UI panels
  • Start each clip from a "neutral" state: nothing hovered, no dropdowns open
  • Scroll slowly — 1 pause at the top, 1 pause at the bottom of long panels
  • Mention the exact name of the thing you're clicking (not "click here" — "click Enroll Users")
❌ DON'T
  • Leave the cursor sitting on a button or link when you pause
  • Resize the browser window mid-recording
  • Click through tabs rapidly without pausing on each one
  • Say "click this" or "over here" — give the actual UI element name
  • Open and close dropdowns to show options unless you pause on the open state
  • Record the same workflow twice with slightly different window sizes
  • Rush through the last few steps because they "seem obvious"
  • Leave loading spinners or skeleton states in your pauses

📁 Recommended File Structure

Deliver these files together for the fastest possible guide generation:

Main recording(s):

workflow-name-part1.mp4
workflow-name-part2.mp4

Supplemental clips (optional but valuable):

workflow-name-properties-tabs.mp4
workflow-name-settings-detail.mp4

Transcripts (same base name as video):

workflow-name-part1.json
workflow-name-part2.json

Outline notes (plain text or paste into chat):

workflow-name-outline.txt

✅ Post-Recording Checklist (Before Sharing With Claude)

1
Run transcription tool and export JSON. Confirm file is named to match the video.
2
Scan the transcript output — are any technical terms (activity codes, platform names) garbled? Note the timestamps if so and flag them manually.
3
Write or paste your outline with approximate timestamps for each section boundary and any callout notes. Even rough timestamps like "~0:18 KB note" are enough.
4
Note the total number of steps and whether there are multiple "Parts." This becomes the guide's structure — clarifying it upfront skips the first clarifying question.
5
If any settings panel has multiple tabs (like Properties), confirm whether you recorded a dedicated supplemental clip for it or want it extracted from the main video.
6
Drop all files (video, JSON, outline) into the workspace folder, then open Cowork and say: "I have a video inside this folder. Make a guide from it."

Keep this open on a second monitor while recording, or print it. The goal is zero back-and-forth: video + transcript + outline in = finished guide out.
